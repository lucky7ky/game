2026年10月1日（木）に、エターナルリターンの**12.5アップデート**が行われました。公式のパッチノートはとても長いので、この記事では**初心者〜中級者が知っておくと得する変更**だけを選んでまとめています。

細かい数値や全部の変更は、必ず[公式の12.5パッチノート](https://playeternalreturn.com/posts/news/3867?hl=ja-JP)で確認してください。

## 3行でまとめると

1. 両手剣で味方を守る**新キャラ「セレス」**が登場（ランク対戦で使えるのは10月6日（火）以降）
2. Kioskで**「先に買うべき特殊材料」に目印が付く**ようになり、買い物で迷いにくくなった
3. 迷惑なプレイヤーを個別に止められる**「ブロック機能」**が追加。キャラ調整はシャーロット・ビヒョン・ニッキーなどが弱体化、ヒョヌ・エレナ・アヤなどが強化

## 一番大きい変更：新キャラ「セレス」

両手剣を持った、**味方を守るのが得意なキャラ**です。

- **通常攻撃**を当てると、相手に少しずつダメージを与える効果が付く
- **Q**：前に突進してバリア（シールド）を張る。その後もう一度押すと剣で突いて、相手を短い時間**動けなくする（気絶）**
- **W**：剣を大きく振って、周りの敵を**吹き飛ばして遅くする**
- **E**：指定した味方のところへ跳んで、しばらく**その味方が受けるダメージの一部を肩代わり**する。ルチアに使うと効果が少し強くなる
- **R**：その場で剣を掲げ、**自分と周りの味方にバリアを付け続ける**。発動中は止められない

リリースから2週間は9,900 A-Coinで販売されます。**10月6日（火）まではランク対戦で使えない**ので、まずは通常対戦で試してみましょう。味方を守るキャラなので、**チームで声をかけ合える人**に向いています。

## 新しいシステム・便利機能

- **Kioskの特殊材料に目印**：ルートの目標アイテムのうち一番左のものに必要な特殊材料に、**黄色い三角**が付くようになった。「何を買えばいいかわからない」という初心者にはかなりうれしい変更（設定でOFFにもできる）
- **ブロック機能**：しつこいフレンド申請・チーム招待・個人チャットを、相手を選んで止められるようになった。相手には通知されない。フレンドリストのメニュー名は「コミュニティ」に変わった
- **画面に出る文字の量を調整**：ダメージの数字や熟練度の経験値などの表示を、項目ごとにON/OFFできるようになった（「設定 ＞ ゲーム」）。画面がごちゃごちゃして見にくい人におすすめ
- **マッチング中でも製作所が使える**ようになった
- NP商品を買うとおまけがもらえる「NP購入スタンプ」が追加（課金する人向けの仕組みなので、無課金なら気にしなくてOK）

## 装備の主な変更

| 装備 | 強化/弱体化 | 変更 |
|---|---|---|
| 星のかけら（腕） | 弱体化 | 12.4で追加されたばかりの装備。スキル増幅 85 → 80、最大体力 250 → 230 |
| 血色のマント（服） | 調整 | スキル増幅 22 → 14 に下がったが、装備効果のダメージは上がった |
| 宇宙飛行士のヘルメット（頭） | 調整 | スキル増幅 57 → 50 に下がったが、装備効果のダメージは上がった |
| 白夜の冠（頭） | 強化 | スキル増幅 70 → 75 |
| クラダリング（腕） | 強化 | スキル増幅 55 → 60 |
| ブラックマンバキング（VF義手） | 弱体化 | 与えたダメージで回復する割合 10% → 8% |

## キャラの主な調整

一部だけ抜き出しています。全キャラの変更は公式パッチノートで確認してください。

| キャラ | 強化/弱体化 | 変更 |
|---|---|---|
| ヒョヌ | 強化 | 足踏み(Q)の序盤のダメージが上がり、クールダウン（次に使えるまでの時間）も短くなった |
| エレナ | 強化 | クリスタルエレガンス(Q)のダメージが上がった |
| アヤ | 強化 | 二連発(Q)と固定射撃(W)のダメージが上がった |
| フェンリル | 強化 | 鋭い爪(Q)の回復量が上がった |
| バーバラ | 強化 | 超高出力イオンレーザー(RW)のダメージ 200/250/300 → 200/300/400 |
| ブレア | 強化 | 基本防御力 47 → 50 |
| シャーロット | 弱体化 | レベルごとの防御力 2.9 → 2.6（12.4に続いて2回連続の弱体化） |
| ビヒョン | 弱体化 | 宴の始まりだ！(R)のダメージ 150/300/450 → 120/270/420 |
| ニッキー | 弱体化 | 怒りのアッパーカット!(R)のダメージ 100/180/260 → 80/155/230 |
| 莉央 | 弱体化 | 短弓の離れ(W)で相手を遅くする効果 30% → 25%、連射(R)の壁ドン気絶 1.2秒 → 1秒 |
| イシュトヴァーン | 弱体化 | 観測(Q)のダメージが下がった |
| アドリアナ | 弱体化 | カクテルパーティー(R)のダメージが下がった |

このほか、**ニア・マーカス・フィオラ**は「スキルの効果時間が本来より短くなっていた」不具合が直り、実質的に少し強くなっています。

## 初心者へのひとこと

今回いちばん初心者にうれしいのは、キャラ調整よりも**Kioskの黄色い三角マーク**です。何を買うか迷う時間が減ると、そのぶん安全に動けます。設定は最初からONになっているので、次の試合で一度チェックしてみてください。

自分の使っているキャラが弱体化された場合でも、初心者のうちはキャラを変えるより、**同じキャラを使い続けて慣れる**方が勝ちやすいです。
